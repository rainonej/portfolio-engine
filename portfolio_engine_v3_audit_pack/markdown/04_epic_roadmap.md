# Epic roadmap (source layout)

The HTML report **`report/04_epic_roadmap.html`** is generated from **one Markdown file per epic** under [`epics/`](../epics/). Do not duplicate epic bodies here; edit the epic files and run `pnpm run build:audit-report`.

The ticket view **`report/05_ticket_backlog.html`** is built from [`tickets/tickets_by_epic.md`](../tickets/tickets_by_epic.md).
