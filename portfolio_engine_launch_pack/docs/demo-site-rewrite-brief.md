# Demo-site rewrite brief

The demo-site should prove Portfolio Engine can build personal/professional websites without itself looking like a personal website.

## Hard requirements

- No public `Résumé` nav item.
- No public generic `Contact` nav item unless reframed as `Contribute`.
- No booking funnel.
- No Calendly.
- No “Book a 15-minute walkthrough.”
- No fake testimonials.
- No fake customer proof.
- No copy implying the demo-site is a generated personal site.

## Public identity

The demo-site should be a project showcase and contributor onboarding site.

Top-level nav should be:

- Vision
- Workflow
- Architecture
- Features
- Examples
- GitHub
- Contribute

## Proof, not testimonials

If a social-proof-like section is needed, use neutral proof cards:

- Reference consumer
- Typed contracts
- Reviewable workflow
- No fake customer proof

Do not invent quotes or people.

## CTA strategy

Primary CTAs:

- Read the vision
- See the workflow
- Inspect the code
- Open an issue

Avoid:

- Book a walkthrough
- Schedule
- Contact us
- Start your site as a private funnel
