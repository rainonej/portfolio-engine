# Open-source policy

Portfolio Engine is intended to be part of the open-source community.

## License

The code is licensed under Apache License 2.0 unless otherwise stated.

## Why Apache-2.0

Apache-2.0 is a permissive open-source license with commercial and noncommercial use, modification and redistribution rights, an express patent grant, a NOTICE mechanism, and clear trademark separation.

## What open source does and does not do

Open source allows broad use of the code.

It does not automatically grant trademark rights, endorsement rights, rights to private downstream content, rights to secrets/credentials/private data, or permission to misrepresent authorship.

## Citation and notification

Citation is appreciated when Portfolio Engine materially contributes to research, teaching, public-facing writing, products, or sites.

Notification is appreciated when Portfolio Engine is used in downstream work, but it is not required by the Apache-2.0 license.

## AI training and scraping

The maintainer requests responsible use with attribution. The open-source license should not be read as an invitation to misrepresent authorship, ignore privacy, or ingest private downstream data.

Any stronger AI-training restrictions would require a different license strategy and may no longer qualify as open source.
