# Gitignored local files (contributors)

These paths are **intentionally not committed**. They may exist on your machine after setup or tooling runs. Keeping them out of git avoids leaking secrets, duplicating personal MCP config, or committing build artifacts.

| Path / pattern                                   | Purpose                                                                                                          | How to create / refresh                                                                                                                                                                                                             |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`.mcp.json`** (repo root)                      | Claude Code **project-scoped** MCP servers (`vercel`, `context7`, `playwright`, …).                              | Copy from [`docs/downstream/templates/agent/mcp.example.json`](../downstream/templates/agent/mcp.example.json) or use `claude mcp add --scope project …`. See [`docs/downstream/agent-tooling.md`](../downstream/agent-tooling.md). |
| **`.cursor/mcp.json`**                           | Cursor **workspace** MCP config (separate from Claude).                                                          | Copy from the same template into `.cursor/mcp.json` (see agent-tooling). Cursor does **not** read repo-root `.mcp.json`.                                                                                                            |
| **`mcp-list-verify.txt`**                        | Optional scratch log from `claude mcp list \| Tee-Object …`.                                                     | Delete anytime; not required for CI.                                                                                                                                                                                                |
| **`.smoke-packs/`**                              | Tarballs from **`pnpm smoke:packed`** (the temp consumer dir is under OS `tmpdir` and is removed after the run). | Safe to delete anytime. On **Windows** the script runs **`astro check` only** (Vercel adapter `astro build` uses symlinks); **Linux CI** runs **`astro check` + `astro build`**.                                                    |
| **`examples/demo-site/.vercel/`**                | Local output from `astro build` with `@astrojs/vercel`.                                                          | Gitignored so Vercel layout is not committed; CI builds clean.                                                                                                                                                                      |
| **`.playwright-mcp/`**                           | Scratch output from Playwright MCP runs in the repo.                                                             | Safe to delete; do not commit.                                                                                                                                                                                                      |
| **`.env`**, **`.env.*`** (except `.env.example`) | Secrets, OAuth client IDs, `SITE_URL`, etc.                                                                      | Copy from each example’s `.env.example` where present.                                                                                                                                                                              |

Related (not always gitignored globally, but local-only in practice):

- **`%USERPROFILE%\.claude.json`** — Claude Code user + per-project settings (including **`claude mcp add --scope local`** entries). Back up before bulk edits.
- **`%USERPROFILE%\.cursor\mcp.json`** — Cursor **global** MCP (all workspaces).

When you open a PR, confirm **`git status`** does not list the files above (except inside ignored paths, which should not appear as tracked changes).
