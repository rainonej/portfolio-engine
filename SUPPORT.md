# Support

Portfolio Engine is currently a maintainer-led open-source project.

Use GitHub issues for bug reports, feature requests, documentation gaps, downstream integration questions, and contribution proposals.

For support requests, include:

- what you are trying to do;
- package versions;
- repo layout;
- commands run;
- error messages;
- whether you are working in the upstream monorepo or a downstream consumer repo.

Do not ask security questions in public issues if they involve vulnerabilities, secrets, or private data. See `SECURITY.md`.

No formal paid support program exists yet.
